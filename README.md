# Тренажёр распознавания конфликтогенов (Telegram-бот)

Бот на Python + aiogram 3. Он выдаёт конфликтную ситуацию (фразу), а пользователь
отмечает все **конфликтогены** — паттерны деструктивной обратной связи, «зашитые»
в эту фразу. Бот проверяет ответ, показывает, что было верно, что пропущено, что
лишнее, объясняет это и считает прогресс.

## Возможности
- 🎯 Тренировка: выбор сферы жизни → выбор темы → фраза → выбор конфликтогенов (inline-кнопки с переключением ✓/•) → «Готово» → разбор.
- ✅ Разбор ответа: верно / пропущено / лишнее + пояснение.
- 📊 Прогресс: попытки, точность (суммарная по всем попыткам), упражнения, пройденные хотя бы раз, статистика по каждому конфликтогену (сколько раз появлялся / сколько раз найден / лишних отметок). Счётчики общие для всех сфер и тем.
- 🔄 Умный выбор: сначала непройденные упражнения (в пределах выбранной сферы и темы), затем по кругу.
- 📝 Данные легко редактировать — только четыре JSON-файла, код менять не нужно.

## Запуск

Требуется Python 3.9+.

```bash
# 1) Виртуальное окружение и зависимости
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt

# 2) Токен
#    Создайте файл .env в корне (шаблон в .env.example) и вставьте токен от @BotFather:
#       BOT_TOKEN=123456:ABC...

# 3) Запуск (из корня проекта)
python -m bot.main
```

Альтернатива для Windows — просто двойной клик по `run.bat` (создаст venv и установит
зависимости при первом запуске).

## Как добавить свои данные

Всё живёт в папке `data/`. Измените эти четыре файла и перезапустите бота — код
подхватит новые данные автоматически.

### `data/domains.json` — сферы жизни (группы упражнений)
```json
{
  "domains": [
    {"id": "work", "name": "Работа", "icon": "💼"},
    {"id": "family", "name": "Семья", "icon": "👨‍👩‍👧"}
  ]
}
```
- `id` — стабильный ключ (латиницей, без пробелов). Используется в поле `domain`
  каждого упражнения и в callback'ах. Держите коротким: `dom:<id>` должен
  укладываться в 64 байта callback_data Telegram.
- `name` — подпись кнопки выбора сферы (до 62 символов).
- `icon` — необязательный эмодзи-префикс кнопки (до 16 символов); без него
  кнопка показывает только название. Итоговая подпись «icon + пробел + name»
  должна укладываться в 64 символа — иначе бот не запустится и укажет,
  какое поле сократить.

Список не может быть пустым, id — уникальны. Чтобы добавить сферу, допишите
запись и перезапустите бота, а новые упражнения помечайте её `id` в поле
`domain` — код менять не нужно. Сфера без тем или упражнений допустима:
при выборе сферы без тем бот покажет подсказку, что темы скоро появятся,
а при выборе темы без упражнений — что упражнения скоро появятся.

### `data/subjects.json` — темы (субъекты) внутри сферы
```json
{
  "subjects": [
    {"id": "salary", "name": "Зарплата и оплата", "domain": "work"},
    {"id": "chores", "name": "Быт и дом", "domain": "family"}
  ]
}
```
Темы — второй уровень выбора: после сферы пользователь выбирает тему, и
тренировка идёт только упражнениями этой пары «сфера + тема».
- `id` — стабильный ключ (латиницей, без пробелов). Используется в поле `subject`
  каждого упражнения и в callback'ах. Держите коротким: `sub:<id>` должен
  укладываться в 64 байта callback_data Telegram.
- `name` — подпись кнопки выбора темы (до 62 символов).
- `domain` — **id сферы** из `domains.json`, к которой относится тема.
  Поле обязательно; неизвестный id — ошибка данных при старте.

Список не может быть пустым. id тем уникальны **глобально, во всём файле** —
один и тот же id нельзя использовать в двух разных сферах: он попадает в
callback `sub:<id>` и должен однозначно определять тему. Тема без упражнений
допустима: при её выборе бот покажет подсказку, что упражнения скоро появятся.
Чтобы добавить тему, допишите запись и перезапустите бота, а новые упражнения
помечайте её `id` в поле `subject` — код менять не нужно.

### `data/conflictogens.json` — список конфликтогенов (меню)
```json
{
  "conflictogens": [
    {"id": "generalization", "name": "Генерализация (Обобщение)", "description": "Утверждение о регулярности или повсеместности поведения. Маркеры: «всегда», «постоянно», «никогда»."},
    {"id": "ratings", "name": "Оценки", "description": "Оценки («4 из 5», «тянет на троечку») без явного требования их давать."}
  ]
}
```
- `id` — стабильный ключ (латиницей, без пробелов). Используется внутри бота и в упражнениях.
  Держите коротким: callback_data в Telegram ограничен 64 байтами.
- `name` — подпись кнопки, которую видит пользователь.
- `description` — необязательное короткое пояснение (показывается в справке и в разборе; при отсутствии бот просто не выводит его).

### `data/exercises.json` — библиотека упражнений
```json
{
  "exercises": [
    {
      "id": 1,
      "phrase": "«Твои презентации на демо заставляют меня краснеть перед коллегами»",
      "conflictogens": ["accusation_shame", "aggression"],
      "domain": "work",
      "subject": "meetings",
      "note": "Попытка вызвать чувство стыда, привязывая результат к неловкому положению перед коллегами (accusation_shame). Подача косвенная, с вовлечением третьей стороны — черта пассивной агрессии (aggression)."
    }
  ]
}
```
- `id` — уникальный номер (целое).
- `phrase` — текст конфликтной ситуации.
- `conflictogens` — **список id** из `conflictogens.json`, которые «зашиты» в фразу (ровно те, что надо отметить).
  Поле обязательно и должно быть списком, но **пустой список `[]` допустим** — это
  контрольный пример: в фразе нет конфликтогенов, и правильный ответ — не отметить ничего.
- `domain` — **id сферы** из `domains.json`, к которой относится упражнение.
  Поле обязательно; неизвестный id — ошибка данных при старте (бот назовёт
  запись и список доступных id).
- `subject` — **id темы** из `subjects.json`. Поле обязательно; тема должна
  существовать **и относиться к той же сфере**, что и упражнение (несовпадение
  `subject.domain` и `domain` — ошибка данных при старте: бот назовёт запись,
  тему и обе сферы).
- `note` — необязательное пояснение к разбору.

> В репозитории уже есть готовый набор: 2 сферы («Работа» и «Семья»),
> 12 тем (6 в каждой сфере), 7 конфликтогенов и 188 упражнений: 88 в сфере
> «Работа» и 100 в сфере «Семья». В наборе 22 контрольных примера с пустым
> `conflictogens`: 10 рабочих (id 79–88) и 12 семейных (id 89–100).
> При желании замените его своей классификацией и библиотекой.

Тематические источники для семейных упражнений перечислены в
[`data/family_sources.md`](data/family_sources.md).

## Команды
- `/start` — главное меню.
- `/stats` — прогресс.
- Кнопки: «Начать тренировку» (сначала предлагает выбрать сферу жизни,
  затем тему внутри неё), «Мой прогресс», «Что такое конфликтоген».

## Эксплуатация
- Остановка: Ctrl+C — бот просто перестаёт опрашивать Telegram (polling),
  ничего не «запоминается» незавершённым.
- Прогресс хранится в `storage/users.json` и сохраняется между перезапусками.
- Сбросить прогресс пользователя: удалить `storage/users.json` — бот создаст
  файл заново при первой же записанной попытке.
- Если новый набор упражнений повторно использует существующие id, сохранённый
  прогресс может привязаться к другим фразам. При замене библиотеки удалите
  `storage/users.json`, чтобы начать с чистого листа.
- Ошибки в файлах `data/` (битый JSON, отсутствующие обязательные поля `name`/
  `phrase`/`id`/`domain`/`subject`, неверный тип значения, неизвестные id
  конфликтогенов, сфер или тем, тема, не относящаяся к сфере упражнения) —
  бот не запускается, но печатает конкретное сообщение, а не traceback.
- Повреждённый `storage/users.json` не ломает запуск: файл откладывается в
  сторону (переименовывается с меткой времени) и прогресс начинается с чистого
  листа.

## Замечания
- В /stats «Пройдено упражнений» — это упражнения, выполненные хотя бы раз
  (не «решённые без ошибок»); «Точность» — доля собранных правильных
  конфликтогенов по всем попыткам суммарно (суммарных правильных / всех
  возможных).
- Двухуровневый выбор: после «Начать тренировку» бот предлагает выбрать сферу,
  затем тему внутри неё, и тренировка идёт только упражнениями этой пары
  «сфера + тема»; «➡️ Следующее упражнение» остаётся в выбранной сфере и теме.
  Если в теме пока нет упражнений, бот отвечает подсказкой «В теме «…» пока нет
  упражнений — они скоро появятся.»; если в сфере нет тем — «В сфере «…» пока нет
  тем — они скоро появятся.» Прогресс при этом общий: /stats суммирует попытки
  и счётчики по всем сферам и темам.
- Контрольные примеры (пустой `conflictogens`): правильный ответ — не отметить
  ничего. В разборе вместо счёта бот пишет «🎉 Верно: в этой фразе нет конфликтогенов»
  (ответ верный) или «🚫 В этой фразе не было конфликтогенов — отмечать ничего не
  нужно было» (были лишние отметки). В /stats контрольные примеры вносят вклад
  только в «лишние отметки» (ложные срабатывания) по конфликтогенам и никогда не
  попадают в «появлений/найдено». Промпт и клавиатура не отличаются от обычных
  упражнений — пользователь заранее не видит, что пример контрольный.
- Бот рассчитан на личные чаты. В группах/супергруппах он молчит на обычные
  текстовые сообщения, а `/stats` вместо личной статистики подсказывает
  открыть её в личке.
- Хранение прогресса — простой JSON-файл (безопасно для одного бота). Для
  продакшена легко заменить на SQLite/Postgres, сохранив интерфейс `Store`.
- Бот работает в режиме polling — сервер/вебхук не нужны.
